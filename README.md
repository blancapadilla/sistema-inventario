# Sistema de Inventario

Proyecto académico en desarrollo enfocado en el registro, consulta y organización de productos mediante una página web.

## Descripción

El Sistema de Inventario es una página web académica creada para llevar un mejor control de productos. El proyecto permite organizar información básica del inventario, como productos, existencias y datos relacionados con el control de mercancía.

Actualmente el proyecto se encuentra en desarrollo y se está trabajando en la implementación de nuevas funciones para mejorar la gestión de información.

## Problema identificado

El problema principal es la falta de organización en el control de inventario. Cuando los productos se registran de forma manual o sin una herramienta adecuada, pueden presentarse errores en las cantidades, pérdida de información y dificultad para saber qué productos están disponibles.

## Solución propuesta

La solución consiste en desarrollar una página web que permita registrar y consultar productos de manera sencilla, ayudando a tener la información más ordenada y accesible.

## Objetivo del proyecto

Desarrollar una página web académica para el control de inventario, permitiendo registrar, consultar y organizar productos de forma clara.

## Tecnologías utilizadas

## Funcionalidades actuales

- Diseño de página web para inventario.
