# Resumen del Proyecto - Sistema de Inventario

## Nombre del proyecto

Sistema de Inventario

## Descripción general

El Sistema de Inventario es un proyecto académico en desarrollo enfocado en el registro, consulta y organización de productos mediante una página web. Su propósito es apoyar el control básico de inventario, permitiendo que la información de los productos se encuentre más ordenada y sea más fácil de consultar.

Este proyecto busca representar una solución sencilla para negocios o empresas que necesitan llevar un mejor control de sus productos, cantidades y datos principales.

## Problema identificado

El problema principal es la falta de organización en el control de inventario. Cuando los productos se registran de forma manual o sin una herramienta adecuada, pueden presentarse errores en las cantidades, pérdida de información, dificultad para consultar productos y problemas para saber qué artículos están disponibles.

## Solución propuesta

La solución consiste en desarrollar una página web que permita registrar y consultar productos de manera sencilla. La página busca facilitar la organización de la información del inventario y servir como base para futuras mejoras, como conexión con base de datos, control de existencias y reportes.

## Objetivo general

Desarrollar una página web académica para el control de inventario, permitiendo registrar, consultar y organizar productos de forma clara y sencilla.

## Objetivos específicos

* Diseñar una interfaz sencilla para el usuario.
* Registrar información básica de productos.
* Consultar productos registrados.
* Organizar la información del inventario.
* Facilitar la visualización de datos importantes.
* Preparar el proyecto para futuras mejoras.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* Visual Studio Code

## Estado del proyecto

El proyecto se encuentra en desarrollo. Actualmente se trabaja en la estructura visual de la página web y en la organización básica de información del inventario.

## Beneficios esperados

* Mejor organización de productos.
* Consulta más rápida de información.
* Reducción de errores en el control manual.
* Base para futuras funciones del sistema.
* Apoyo en la gestión básica del inventario.
