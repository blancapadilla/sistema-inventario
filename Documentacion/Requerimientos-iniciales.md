# Requerimientos Iniciales - Sistema de Inventario

## Introducción

Este documento presenta los requerimientos iniciales del Sistema de Inventario, un proyecto académico en desarrollo que consiste en una página web para registrar, consultar y organizar productos de manera básica.

Los requerimientos aquí definidos sirven como guía para continuar el desarrollo del proyecto y mejorar sus funcionalidades.

## Requerimientos funcionales iniciales

### RF01 - Mostrar pantalla principal

La página web debe mostrar una pantalla principal clara, donde el usuario pueda identificar el propósito del sistema de inventario.

### RF02 - Registrar productos

La página web debe permitir registrar información básica de productos, como nombre, categoría, cantidad y descripción.

### RF03 - Consultar productos

La página web debe permitir visualizar los productos registrados en una lista o sección de consulta.

### RF04 - Organizar productos

La página web debe mostrar la información de los productos de manera ordenada para facilitar su lectura.

### RF05 - Editar información de productos

La página web deberá permitir modificar información de productos registrados en futuras versiones del proyecto.

### RF06 - Eliminar productos

La página web deberá permitir eliminar productos que ya no formen parte del inventario en futuras versiones.

### RF07 - Buscar productos

La página web deberá contar con una opción para buscar productos por nombre o categoría.

### RF08 - Controlar existencias

El sistema deberá permitir visualizar la cantidad disponible de cada producto.

### RF09 - Identificar bajo inventario

El sistema deberá permitir identificar productos con poca existencia para facilitar el reabastecimiento.

### RF10 - Mostrar información clara

La página web debe presentar la información del inventario de forma sencilla, clara y entendible para el usuario.

## Requerimientos no funcionales

### RNF01 - Facilidad de uso

La página web debe tener una interfaz sencilla para que el usuario pueda utilizarla sin dificultad.

### RNF02 - Diseño ordenado

El diseño debe ser limpio, claro y fácil de entender.

### RNF03 - Rendimiento

La página web debe cargar correctamente y permitir consultar la información sin problemas.

### RNF04 - Escalabilidad

El proyecto debe permitir agregar nuevas funciones en el futuro, como base de datos, reportes o semáforo de inventario.

### RNF05 - Mantenimiento

El código y la documentación deben organizarse de manera que sea fácil realizar modificaciones futuras.

## Funcionalidades actuales

* Diseño inicial de la página web.
* Organización básica de productos.
* Interfaz visual para el control de inventario.
* Consulta básica de información.

## Funcionalidades pendientes

* Conexión con base de datos.
* Registro completo de productos.
* Edición y eliminación de productos.
* Control de existencias.
* Semáforo de inventario.
* Reportes básicos.

## Conclusión

Estos requerimientos iniciales permiten definir las funciones principales del Sistema de Inventario y sirven como base para continuar con el desarrollo del proyecto.
